Donnez-lui un nom et, si vous voulez, un mot de passe. Votre émulateur trouve votre adresse sur Internet et demande à votre box d'ouvrir un port. => 给房间起个名字，也可以设置密码。模拟器会获取你的公网地址，并请求路由器开放端口。
2. Partagez le code => 2. 分享代码
Le code contient tout ce qu'il faut pour vous joindre, jusqu'à 7 amis. Aucun compte. => 代码包含连接你所需的一切，最多 7 位好友。无需账号。
3. Choisissez le jeu => 3. 选择游戏
Chacun vérifie automatiquement qu'il a exactement le même fichier que vous. => 每个人都会自动检查文件是否与你的完全相同。
Ça ne passe toujours pas ? => 还是连不上？
Utilisez Radmin VPN, Hamachi ou Tailscale : l'émulateur passe directement par eux, sans réglage. => 使用 Radmin VPN、Hamachi 或 Tailscale：模拟器会直接通过它们连接，无需设置。
Chacun joue SON jeu avec SA sauvegarde, reliés par le câble Game Boy (échanges Pokémon...). 2 joueurs. => 每人用自己的游戏和存档，通过 Game Boy 连接线相连（交换宝可梦...）。2 名玩家。
Chacun joue SON jeu avec SA sauvegarde. Le câble GBA ne marche qu'avec : Pokémon Rubis, Saphir, Émeraude, Rouge Feu, Vert Feuille (et leurs hacks) et Advance Wars 1 et 2. Pour les autres jeux (Mario Kart...), le core gpSP ne sait pas émuler le câble. => 每人用自己的游戏和存档。GBA 连接线仅支持：宝可梦 红宝石、蓝宝石、绿宝石、火红、叶绿（及其改版）和 Advance Wars 1、2。其他游戏（马里奥赛车...）的连接线 gpSP 核心无法模拟。
Chacun joue SON jeu avec SA sauvegarde, reliés en sans-fil DS (jusqu'à 4). Le sans-fil DS exige un ping très faible : il marche sur un même réseau, rarement par Internet. => 每人用自己的游戏和存档，通过 DS 无线连接（最多 4 人）。DS 无线需要极低的延迟：在同一网络中可用，通过互联网很少成功。
